# learning_notes：多模态后训练学习笔记（第一版）

## 1. 什么是多模态后训练（Post-training）
- **预训练**：从海量通用数据学习通用视觉与语言能力（成本高、周期长）。
- **后训练**：在已有开源模型基础上，用任务相关数据进行继续训练，使模型适配特定场景。
- 本项目采用后训练，因为目标是：
  1) 10 天可交付；
  2) 工程可复现；
  3) 面试可解释。

## 2. 为什么不做从零预训练
- 资源和时间不匹配：预训练通常需要多卡大集群。
- 求职项目更看重端到端闭环与工程能力，而不是烧算力。
- 后训练更容易把“业务任务定义→数据设计→评测指标”讲清楚。

## 3. 为什么优先 LoRA / QLoRA
- LoRA 只训练少量低秩适配参数，显存和时间成本低。
- QLoRA 在低比特量化下训练，进一步降低显存占用。
- 对单卡友好，适合“先跑通再迭代”的项目节奏。

## 4. 数据如何构造（本项目设定）
目标三任务：
1. 是否异常（binary）
2. 缺陷类型（multi-class）
3. 缺陷位置（九宫格）

构造思路：
- 从数据集目录结构/标签/mask 读取监督信息。
- 将单样本转换成多条问答或指令样本（增强监督密度）。
- 输出统一 JSONL，便于替换模型与调试。

## 5. 指标如何理解
- 任务 1/2：Accuracy + F1（兼顾总体正确率和类别不均衡）。
- 任务 3：九宫格位置准确率（粗粒度空间理解能力）。
- 额外导出成功/失败案例，支持可解释分析。

## 6. 工程结构的意义
- `scripts/`: 面向运行命令的入口（prepare/train/eval/infer）。
- `src/`: 可复用核心逻辑（数据构建、指标、模型工具）。
- `configs/`: 训练和评测参数外置，便于复现实验。
- `docs/`: 学习、决策、面试、服务器运行指南。

## 7. 第一阶段学习重点
- 明确“任务定义 > 模型炫技”。
- 先完成最小闭环，再扩展数据规模和方法复杂度。
- 文档与实验日志同样是交付物，不是附属品。
